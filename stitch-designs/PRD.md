# Mandate — AI Executive Search Operating System

## I. CORE PLATFORM FOUNDATION
1. Multi-Tenant Workspace System (Organizations, Workspaces, Users, RLS)
2. Project / Search Mandate Engine (System of record for each hire)

## II. ROLE INTELLIGENCE SYSTEM
3. One-Line Role Input Engine (Input -> Role structure, inferred scope)
4. Job Spec Generation & Versioning (AI-generated, company-aware, version control)
5. Role Decomposition Engine (Engineering vs Ops, contradictions, "what client REALLY wants")

## III. COMPANY INTELLIGENCE
6. Company Research Engine (Industry, org structure, tech maturity)
7. Company Context Layer (Drives job spec and scoring)

## IV. ONBOARDING & CALIBRATION
8. Dynamic Onboarding Questionnaire (Must-haves, anti-patterns, priorities)
9. Calibration Engine (Converts onboarding -> scoring model)
10. Calibration History (Track evolution)

## V. SOURCING INTELLIGENCE
11. Boolean Search Generator (LinkedIn, Google X-Ray, ATS)
12. Sourcing Strategy Engine (Target companies, archetypes)
13. Query Management (Save, version, regenerate)

## VI. CANDIDATE INTELLIGENCE
14. CV Parsing System (Structured profile extraction)
15. Candidate Profile Engine (Roles, domain, tech exposure, archetype)
16. Candidate Analysis Engine (Summary, strengths/weaknesses, fit)
17. Archetype Classification (Builder, Operator, Transformer, etc.)

## VII. COMPARISON & RANKING (CORE DIFFERENTIATOR)
18. Comparative Scoring Engine (Technical, domain, scale, regulatory, transformation)
19. Ranking Engine (Tier 1/2/3/4)
20. Cumulative Ranking (Persistent leaderboard)
21. Multi-Perspective Ranking (Engineering-first, Low-risk, etc.)
22. Rank Change Explanation (Why moved up/down)

## VIII. FEEDBACK & LEARNING SYSTEM
23. Feedback Ingestion (Recruiter, Hiring Manager, Interview)
24. Feedback Interpretation (Detect preference changes, bias)
25. Recalibration Engine (Update scoring, re-rank)

## IX. SHORTLIST & DECISION ENGINE
26. Shortlist Builder (Top 3, Top 5)
27. Candidate Comparison (Side-by-side, trade-offs)
28. Decision Support (Scenario analysis)

## X. RECRUITING METRICS & DASHBOARD
29. Candidate Pipeline Tracking (Pipeline stages)
30. Funnel Metrics (Conversion rates)
31. Weekly Metrics Dashboard (Sourcing, ranking changes, feedback)
32. Search Health Engine (Detect stalled searches, poor quality)
33. Source Performance (Channel efficacy)

## XI. REPORTING SYSTEM
34. Report Generation (Submission, Top 3, Progress)
35. Export Capabilities (PDF, DOCX)

## XII. CANDIDATE ADVISORY SYSTEM
36. Candidate Fit Analysis
37. Candidate Positioning (Narrative, perception)

## XIII. PSYCHOLOGICAL INTELLIGENCE
38. Candidate Psychology (Leadership style, risk tolerance)
39. Hiring Manager Psychology (Preferences, bias)
40. Company Culture Intelligence

## XIV. AI AGENT SYSTEM
Core Agents: Intake, Company Research, Onboarding, Role Spec, Calibration, Boolean Search, CV Parsing, Candidate Review, Ranking, Feedback, Shortlist, Candidate Positioning, Recruiter Copilot, Metrics.
