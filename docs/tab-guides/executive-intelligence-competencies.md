# Competencies

The library every executive score is measured against — four categories
of competency, each with a definition and the observable evidence that
counts for and against it.

## What you do here

1. Read a competency's definition before you trust a score that cites
   it.
2. Read **Evidence of strength** and **Evidence of concern** to see what
   an assessor is actually looking for.
3. Use the categories — leadership, functional, operating scale and
   stage, governance and stakeholders — to check a role is weighted
   across more than one.

## What done looks like

You can say what a competency means without guessing, and you can trace
any executive score back to a named, defined one.

## What this screen will not do

**Nothing here can be authored, edited or deleted** — there is no form,
no button and no create path anywhere in the product. The library ships
with Mandate rather than being configured per organisation, which is why
there is nothing to set up.

It has no search, no filter, no sort beyond alphabetical, and no detail
page. It runs no agent and generates nothing: this is reference data,
not advice.

If it ever renders empty, that is ours to fix, not yours — the guide
says so, and so does the screen.

## Where this leads

Back to **Executive Intelligence**. Weights against these competencies
are set on **Role templates**.
