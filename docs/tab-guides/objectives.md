# Objectives

The OKR board: goals the desk is measured by, and key results that
measure themselves from work already recorded.

## What you do here

1. Set an objective and its key results.
2. Watch progress accrue — key results read from placements, candidates
   and activity rather than from anyone typing a number in.
3. Adjust targets when the quarter's shape changes.

## What done looks like

Every objective has key results that move on their own, and none of them
needs a human to update it.

## What this screen will not do

It will not chase anyone, and it does not set targets for you. A key
result it cannot derive from recorded work is one it cannot track.

Every active role can **read** this board — goals the desk is measured
by are visible work. Writing is behind `okrs:write`, so the controls
simply do not appear for a viewer. Financial key results are filtered by
the database, not by this page: without `fees:read` the row never
arrives, and the card renders what arrived.

## Where this leads

To the work itself — **Placements** for revenue goals, **Mandates** or
**Candidates** for pipeline ones.
