# Agents

The whole workforce, named: every AI principal in the product, what each
one judges, the line it is not allowed to cross, and whether it is
running right now.

## What you do here

1. Read the counts at the top — how many principals exist, how many are
   active, how many are suspended.
2. Find the agent behind a piece of work you are questioning, by group:
   understand, discover, evaluate, engage, deliver, assist.
3. Read its **Stays human** line — the judgment that agent is forbidden
   to make on your behalf.

## What done looks like

You can name the agent that produced a given judgment and say what it is
not permitted to decide.

## What this screen will not do

**It cannot start, stop, pause or configure anything.** There is not one
button on it. The status chip reports what the database says; it does
not operate it. Suspending a principal is a founder act from platform
operations, and each agent's kill switch is independent of the other
twenty-four.

It does not show which model an agent runs on, when it last ran, how
often, or what it cost. Model assignment lives in **Settings → Models**.

An agent listed as **not provisioned** is documented here but has no
account in this deployment — the page says so rather than implying it is
working. For the same reason the header count (real accounts) can be
smaller than the number of agents described below it.

The editorial lines quoted here are enforced in the database, not in a
prompt: no agent acts as you, and every judgment lands in the trail
under the agent's own name.

## Where this leads

To **Skills studio**, which is where you actually steer these agents —
they read your instructions on every run. To check an agent's work, read
**Activity**.
