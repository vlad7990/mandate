# Placements

The revenue book. It answers *what did we bill this quarter* as the
headline, rather than as something you reach by filtering a list.

## What you do here

1. Read the quarter's number, then the four quarters behind it.
2. Open the placements that make it up to interrogate any figure.
3. Check what is **booked but not yet earned**.
4. Record a new placement when a candidate is hired.

## What done looks like

Every hire is recorded, and the quarter's number is one you would defend
to the client.

## What this screen will not do

It will not invoice anybody — that is **Invoices** — and it does not
forecast future revenue.

**What each role sees differs, honestly.** A researcher or viewer holds
`org:read` but not `fees:read`, so the database sends them placements
and no fee lines. Rather than showing a revenue page reading zero —
which is a lie, not a restriction — the page says so and shows the
placements without the money columns. A researcher credited on a
placement does see that placement's fee.

## Where this leads

To **Invoices**, to bill what this screen recorded.
