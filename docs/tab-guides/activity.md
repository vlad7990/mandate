# Activity

Who changed what, newest first — including the agents, by name.

## What you do here

1. Scan the trail for what has happened since you last looked.
2. Filter by type — mandates, placements, fees, client-facing — to
   answer a specific question.
3. Use it to check an agent's work: every judgment an agent made is
   recorded under the agent's own name.

## What done looks like

You can answer "who changed this, and when" without asking anyone.

## What this screen will not do

It will not let you undo anything, and nothing here can be edited — the
trail is a record, not a workspace.

Every row was written by the database at the moment of the actual
change, **not by the application remembering to mention it**, so this is
what happened rather than what was reported.

The page has no capability gate, because the honest answer for every
role is "here is what you may see". The database filters the rows: a
viewer sees placement and client-facing events, a recruiter also the
money, an admin also member changes. The filter list is built from what
you can actually see, so you are never offered a filter that returns
nothing.

## Where this leads

To whatever the row is about — every entry links to its subject.
