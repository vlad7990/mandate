# Pool search

Search every candidate you already hold, in plain language, across all
mandates.

## What you do here

1. Narrow the pool with the structural filters — archetype, tier,
   pipeline stage.
2. Describe who you want in a sentence: *"Senior post-trade engineering
   leaders with FCA exposure who've shipped a T+1 migration."*
3. Read the matches, and open anyone worth pursuing.

## What done looks like

You know whether the person you need is already in your pool before you
go looking outside it.

## What this screen will not do

It searches **only candidates you already hold** — it is not a sourcing
tool and it does not reach the open web or LinkedIn.

The structural filters run first. If they match nobody, the agent never
runs and the screen says so plainly rather than returning an empty
result that looks like a judgement.

If the Candidate Search Agent has been suspended by an operator, this
screen says that too, in those words, rather than quietly returning
nothing.

## Where this leads

To a candidate, or to the mandate you were staffing.
