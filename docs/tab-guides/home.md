# Portfolio

Your first screen each morning. It answers four questions in reading
order — what needs you, what changed, what is at risk, what to do next —
so you can triage the whole workspace without opening a single mandate.

## What you do here

1. Read **Needs you today** first. It is the only list on the page
   carrying buttons; everything else is reference. If it is empty, no
   mandate is waiting on you.
2. Scan mandate **health**. Health is a dot and a word — no gauge, no
   green-to-red ramp — because a search is not a score.
3. Open whatever the first list sent you to, and do the work there.

## What done looks like

**Needs you today** is empty, or everything left in it is deliberately
waiting on someone else.

## What this screen will not do

It will not tell you which candidate to advance, and it does not rank
your mandates against each other. Two panels a new workspace shows in
the sample — agent activity and next best action — are **not built
yet**; they appear in the sample so you can see where the product is
going, and are simply absent from a real workspace rather than faked.
The "candidates" tile counts every candidate, not ones awaiting review:
nothing tracks reviewed-versus-unreviewed, so a review count would be a
guess.

## Where this leads

Into a mandate, via **Portfolio** or **Mandates**. Everything else in
Workspace reports on work that starts there.
